# Password Manager (CLI Application)

A secure and user-friendly **command-line Password Manager** built with Python.
This application allows users to store, manage, and retrieve login credentials efficiently.

---

## Features

* User authentication system (username & password)
* Add new account credentials
* View all saved accounts (without exposing passwords)
* Search account by website
* Update account password
* Delete account with confirmation
* Generate secure random passwords
* Reset application (clear all stored data)
* Data stored locally using JSON

---

## Technologies Used

* Python
* JSON (for data storage)
* Standard Libraries:

  * `json`
  * `random`
  * `string`

## How It Works

* On first run, user sets up a **master username and password**
* After login, user can manage stored credentials through a menu
* All data is saved locally in JSON files
* Passwords can be updated, searched, or deleted anytime

* This project stores passwords in plain text (for learning purposes)
* For real-world applications, encryption should be implemented
